# BTPTracker
A web extension that tracks achievement progress in the game Block The Pig.

## To Install

Download and unzip this repository.

### On Chrome

Type `chrome://extensions/` into the URL. On this page, turn on developer mode, click 'Load unpacked' and select the downloaded folder.

### On Firefox

Type `about:debugging#/runtime/this-firefox` into the URL. Click 'Load Temporary Add-on...' and select the downloaded folder. Note that this step will need to be repeated every time Firefox is restarted.
